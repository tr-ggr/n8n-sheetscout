# Sprint 02 — The workflow

## Goal

`workflows/resume-summarizer.json` imports cleanly into n8n and, once credentials are
selected, runs end to end: upload PDF → text → OpenRouter → row in Google Sheets. A
validator guards the JSON's structure in CI.

## Tasks

- [x] `workflows/resume-summarizer.json` with the five nodes and one sticky note described in `docs/architecture.md`, connected linearly in order. Requirements:
  - Top-level keys: `name`, `nodes`, `connections`, `settings` (`executionOrder: v1`), `pinData: {}`. No `id`, `versionId`, `meta.instanceId`, or `credentials` blocks.
  - Node ids are stable UUIDs; positions spaced ~220px apart on one row.
  - Form Trigger 2.2: `formTitle`, `formDescription`, `formFields.values[0]` = `{ fieldLabel: "resume", fieldType: "file", acceptFileTypes: ".pdf", multipleFiles: false, requiredField: true }`, a `webhookId` UUID at node level.
  - Extract From File 1: `operation: "pdf"`, `binaryPropertyName: "resume"`.
  - HTTP Request 4.2: parameters per the table in `docs/architecture.md`; body is the `JSON.stringify` expression (starts with `={{`); node-level `retryOnFail: true`, `maxTries: 3`, `waitBetweenTries: 2000`.
  - Code 2: `mode: "runOnceForEachItem"`, `jsCode` generated by `pnpm sync` (below).
  - Google Sheets 4.5: `operation: "append"`, `documentId: { __rl: true, mode: "id", value: "={{ $env.GOOGLE_SHEET_ID }}" }`, `sheetName: { __rl: true, mode: "name", value: "={{ $env.GOOGLE_SHEET_TAB || 'Candidates' }}" }`, `columns: { mappingMode: "autoMapInputData", value: {}, matchingColumns: [], schema: [] }`, `options: {}`.
  - Sticky note (`n8n-nodes-base.stickyNote` 1) listing the two credentials to create and the env vars to set.
- [x] `scripts/sync-code-node.ts` — reads `src/parse-llm-response.ts`, extracts the text between `// @n8n-code-start` and `// @n8n-code-end`, appends a trailer `\nreturn { json: parseLlmResponse($input.item.json) };`, and writes it into the Code node's `jsCode` in the workflow JSON (pretty-printed, 2 spaces, trailing newline). Idempotent.
- [x] `src/validate-workflow.ts` — exports `validateWorkflow(json: unknown): string[]` (list of problems, empty when valid) and, when run as a script, validates every `workflows/*.json` and exits 1 on problems. Checks:
  - node names/types/typeVersions exactly as in `docs/architecture.md`;
  - connections form the exact linear chain (each node's `main[0]` has one target = next node);
  - Form file field name equals the Extract node's `binaryPropertyName`;
  - HTTP node URL, method, `genericAuthType`, body expression begins with `={{` and references `$json.text` and `response_format`;
  - Code node `jsCode` equals what `sync-code-node` would generate (so a stale JSON fails);
  - Sheets node `mappingMode` is `autoMapInputData`;
  - serialized JSON contains no `credentials` key, no `sk-or-`, no `instanceId`.
- [x] `src/validate-workflow.test.ts` — validates the real file (expects `[]`) and a few mutated copies (wrong binary property, broken chain, stale code) expecting specific messages.
- [x] `README.md` "Import the workflow" section: import via n8n UI (Workflows → Import from file), create the two credentials, assign them on the two nodes, set env vars in `.env` and restart the container, activate, open the form URL, upload `fixtures/sample-resume.pdf`, check the sheet.

## Acceptance criteria

- `pnpm sync` is a no-op on a clean tree (run it, `git status` clean).
- `pnpm validate`, `pnpm typecheck`, `pnpm test` green.
- The JSON is valid n8n import format (structure mirrors real exports: see the n8n docs for `n8n-nodes-base.extractFromFile` examples).

## Out of scope

- Live calls to OpenRouter or Google (cannot run in CI; documented as a manual check).

## Notes / gotchas

- Expressions in n8n parameters are strings that start with `=`; `{{ }}` without the leading `=` is literal text.
- With the Form Trigger the binary property is the **field name** (`resume`), not `data`.
- `$env` access inside nodes requires `N8N_BLOCK_ENV_ACCESS_IN_NODE=false` (already in `.env.example`).
- Keep the system prompt text verbatim from `docs/architecture.md`.
