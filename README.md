# n8n-SheetScout

Resume Summarizer → Google Sheets. An n8n workflow that takes an uploaded PDF resume, extracts
the text, asks an LLM (via OpenRouter) for a structured summary, and appends the candidate as
a row in a Google Sheet.

See `docs/architecture.md` for the design and `docs/sprints/` for the build plan.

## Status

Sprint planning done; implementation in progress (see `docs/sprints/README.md`).
